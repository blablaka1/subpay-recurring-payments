# Глоссарий

| Термин | Определение |
|---|---|
| Merchant | Компания, использующая SubPay для регулярных списаний. |
| Customer | Клиент merchant, за которого создаётся подписка. |
| PSP | Внешний платёжный провайдер, выполняющий реальное списание. |
| Payment method token | Токен карты/платёжного метода, выданный PSP; не является PAN. |
| Subscription | Правило регулярного списания: клиент, сумма, период и платёжный метод. |
| Payment | Одна плановая операция списания по подписке. |
| Attempt | Конкретная попытка выполнить Payment через PSP. |
| Webhook | Асинхронное HTTP-событие PSP о результате платежа. |
| Temporary failure | Ошибка, при которой разрешён повтор (например временный отказ PSP). |
| Permanent failure | Ошибка, при которой автоматический повтор не выполняется. |
