# SubPay Recurring Payments

Учебный fintech-проект сервиса регулярных платежей. Сервис хранит подписку и расписание, но **не хранит PAN/CVV карты**. Платёжный метод представлен токеном внешнего PSP (Payment Service Provider).

## Что демонстрирует кейс

В проекте проработаны задачи системного анализа, связанные с интеграцией с внешним платёжным провайдером, асинхронной обработкой результатов платежа, webhook, повторными попытками, статусной моделью и идемпотентностью.

## Scope v1

- привязка токена платёжного метода к клиенту;
- создание ежемесячной подписки с фиксированной суммой в RUB;
- запуск списания по `next_charge_at`;
- обработка ответа PSP и webhook;
- до двух повторов при временной ошибке;
- пауза, возобновление и отмена подписки;
- просмотр платежей подписки.

За рамками:

- хранение реквизитов карты;
- возвраты/chargeback;
- частичные списания;
- промокоды;
- налоги и чеки;
- сложные тарифы с usage-based billing;
- несколько PSP и smart routing.
