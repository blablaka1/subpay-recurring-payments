# User Stories

## US-SUB-001. Создание подписки

**Как** merchant, **я хочу** создать регулярную подписку для своего клиента, **чтобы** SubPay автоматически инициировал ежемесячные списания.

### Критерии приёмки

1. Создаётся только подписка на customer/payment method текущего merchant.
2. Поддерживаются RUB, MONTHLY и сумма 100–100 000 ₽.
3. Повтор команды с тем же Idempotency-Key не создаёт дубликат.
4. Новая корректная подписка имеет статус `ACTIVE` и заполненный `next_charge_at`.

## US-SUB-002. Управление подпиской

**Как** merchant, **я хочу** приостанавливать, возобновлять и отменять подписку, **чтобы** управлять будущими списаниями.

## US-PAY-001. История платежей

**Как** merchant, **я хочу** видеть платежи и их статусы, **чтобы** понимать результат регулярных списаний.
